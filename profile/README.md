# FAQ

## What is OmniMC?

Omni is a universal Minecraft mod loader and API. It enables both 
Forge and Fabric mods to run simultaneously. Its goal is to ensure 
cross-compatibility with all major Minecraft modding frameworks.

## Why is OmniMC?

Have you ever wanted to add that cool new mod to your Fabric modpack, 
only to discover it's a Forge mod? That's why!
